How It Works

  • 1. NLP Distillation: We extract noun phrases and filter noise using NLTK.
  • 2. Weighted Ranking: Comments are ranked based on Likes, Sentiment, and PMI.
  • 3. Semantic Clustering: Similar ideas are grouped via Sentence-Transformers.
  • 4. LLM Synthesis: Groq (Llama 3) generates the final executive summary.
